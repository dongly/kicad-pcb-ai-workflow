# 已放置字段与丝印修复（经案例验证，2026-11-21）

当最终 DRC 报出 `silk_over_copper`、`silk_overlap` 或 `footprint_symbol_field_mismatch` 时阅读本文。这些是不同的检查：只修复图形并不会同步元件元数据。

## 摸清实际可用的写入器

原版 Konnect 0.13.0 与经查验的官方 0.14.1 提供的 `edit_component` **只能改 value**。它们的 `update_pcb_from_schematic` 可能报告 no-op，而自定义字段依然缺失。`update_footprints_from_library` 会保留实例字段的位置/样式；刷新库不等于修复已放置的位号。请检查运行中的输入 schema，而不是凭工具名推断能力。

Windows LED 案例需要 **开源** 的 0.13.0 配套工具 `set_placed_footprint_fields`。其源码、基础压缩包的精确哈希、许可证与准备命令见仓库的[配套扩展](https://github.com/jackwang988/kicad-pcb-ai-workflow/tree/main/development/konnect-field-extension)。它没有随已安装的 Skill 或商业版 0.14.1 二进制打包。绝不给商业版二进制打补丁/做逆向，也不自动切换后端。缺少字段能力时，应报告该具体不支持的操作；不得把直接写 pcbnew/文件当作隐藏回退。

## 修复循环

1. 绑定当前活动板、可执行文件/构建、KiCad 版本与已发现的 schema。保留一个已保存的检查点与全部原始 DRC 证据。比对封装 UUID、位置、焊盘几何/网络、走线、过孔、覆铜、规则与排除项。
2. 把每条警告解析到其实际归属对象/UUID。区分封装位号、封装轮廓线、板级备注与外露焊盘。基于**原生焊盘/阻焊/图形/文字几何**做规划，并把相邻连接器纳入考虑。首次放置封装时就应预留独立的位号文字区；仅靠本体/courtyard 预留并不够。
3. 优先把实例位号放在阻焊开窗之外、可见且可读的位置。保持实体器件的朝向/摆放及其极性标记。字号与线宽必须满足实际项目/工厂约束；示例使用 0.8 mm / 0.12 mm，并非通用默认值。在局部搜索文字位置；紧邻连接器的位号可能需要向内偏移，而不是套用统一网格。对发生碰撞的板级备注，按观察到的确切 UUID 单独移动并保留其内容。
4. 同步全部目标原理图字段，**包括 Datasheet 与 Description**，而不只是 MPN/厂商/封装/规格。KiCad 可能每个封装只报第一处不匹配：警告数量不变可能掩盖新暴露的下一处。把每个最终值与权威原理图比对。PCB 焊盘特征与可采购器件在 BOM 中角色不同。
5. 配套工具使用一个 dry-run 修订版，绑定当前已录入的封装与所请求的变更。只应用该修订版，把父封装更新放进同一次撤销提交，保留每个非字段的 protobuf 成员，并验证所有字段的新鲜回读。其已测试范围假设四个必填字段存在；其他结构需另行验收。先改一个封装、保存、检查原生几何与完整 DRC，再扩展到经审阅的集合。出现超时或回读未确认时，停止后续编辑，直到查明实际状态。
6. 保存后，独立审计**已保存的文件**，而不只是 MCP 的成功应答。检查完整 ERC/DRC，包括原理图一致性与 unconnected 项。在真实原生渲染中确认位号可读，并核验几何/网络/规则/排除项未被破坏。不得为制造一份干净的报告而隐藏位号、删除原理图字段、关闭检查类别或添加排除项。

## 已保存的项目设置可能过期

某些 Konnect 设计规则工具会编辑项目文件，而 KiCad 仍持有缓存的 Board Setup 值。之后的 `save_project` 可能把它们覆写掉。要在**最后一次 GUI/MCP 保存之后**读取生效的已保存规则。继续设计修改前先对齐缓存状态；若无实时重载可用，则把工程导出绑定到已验证的不可变快照，并在其后任何保存之后重新执行检查。重新应用一次数值并不能证明以后的 GUI 保存都安全，库刷新也解决不了规则缓存问题。

## 该示例证明了什么

[已发布的案例与详细记录](https://github.com/jackwang988/kicad-pcb-ai-workflow/blob/main/docs/r10/07-led-e2e-and-silkscreen.md)记载：135 条阻焊/丝印警告、64 处丝印重叠与 80 处字段不匹配全部清零；核对了 84 个位号与 376 个字段值。全部 205 条走线、168 个焊盘、器件摆放与覆铜 GND 均得到保留。D5/D61 需要在侧面电源焊盘周围做特殊偏移。这些位号名称/坐标仅属该示例，不得变成通用摆放规则。

这是一个原生 Windows/KiCad 10.0.8 案例，不代表字段工具的普适验收或硬件批准。自建可执行文件须走明确的本地登记；二进制哈希/schema 不同则需要相应的首次使用检查。参见[能力迁移](konnect-capability-migration.md)。
