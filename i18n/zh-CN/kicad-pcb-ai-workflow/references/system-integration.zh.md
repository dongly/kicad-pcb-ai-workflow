# 系统架构与跨模块接口门禁

项目必须明确描述系统模块、每个有来源依据的电源域、接口端点、模块所有权、预期的引脚到网络图、电压/逻辑电平、时钟/复位/使能方向，以及运行/安全假设。架构图用于说明，不是网表。每项已声明需求都必须有文档化来源，以及验证任务或真实的外部测试计划。

`system_integration.py` 会将当前 KiCad XML 网表端点与已声明的模块边界及来源契约进行比较。缺少网络、引脚端点拓扑错误、接口实际上并未跨越所声明模块，或来源身份未知，都必须产生与证据关联的发现项。绝不要仅仅为了让错误的原理图看起来正确而修改预期接口规格。

检查总览与层次结构的视觉呈现，验证端口名称和模块角色，并运行真实的原生 ERC。验证器不会设计或绘制原理图，也不会授予 G1 审批。参见[需求模块](module-requirements.md)、[原理图模块](module-schematic.md)和[静态审查](static-ai-review.md)。
