# 原理图设计意图与生效的 PCB 约束

## 意图不等于已实现的板卡

设计意图参数档在物理布线之前记录需求。实际 KiCad 项目必须独立同步并读回。`design_intent.py` 创建原生规则/NetClass 候选；`design_intent_audit.py` 在受支持处检查真实生效的指派。磁盘上存在输入 JSON **不**代表某条规则已在 KiCad 中生效。

## 信号、电源与 RF 约束

- **差分或受控单端链路：**精确的网络/引脚端点、P/N 配对、信号协议/PHY、来自权威接口/工厂来源的目标特性/差分阻抗与容差；允许的层、参考平面、拓扑、过孔约束与偏斜/长度预算。不要要求每条差分总线使用相同阻抗或等长。
- **电源：**标称/最小/最大轨电压、持续/峰值瞬态电流、允许压降/温升、铜厚与包含回流的电流路径。几何尺寸依据认可的制造条件与热估算确定；要研究颈缩与过孔阵列，而不只看最宽一段。
- **RF/天线：**频率、参考地、馈电与匹配布置、认可的电气几何、供电/回流环路、物理天线禁布区（方向须与厂商指引实际相符）。绝不无差别地清空 RF 下方的全部地铜，也不把声明的禁布区轮廓误当作已强制生效的原生铜箔限制。
- **备选项：**0 欧姆/DNP/选择器取值、默认装配状态、互斥组、可能产生的残桩，以及 BOM/CPL 变体影响。

## 应用/读回步骤

```bash
# Generate candidate rules: preview first, then explicit --apply into a new isolated destination.
python scripts/design_intent.py --help
# Verify the current synchronized project's real effective rules/geometry.
python scripts/design_intent_audit.py --help
```

只能用认可的 EDA 写者写入原生项目源。在已保存候选上确认真实网表与生效的 NetClasses/规则约束、叠层、层映射、项目版本与 DRC。尽可能用隔离的负向夹具测试原生规则生效情况。任何不受支持的映射、未绑定网络或不匹配都是阻断性的未决设计约束；不得为得到干净报告而降低规则要求。

## 局限

线宽/间距不能独立证明阻抗、参考平面连续性、SI/PI 或辐射发射。原生板级 DRC、详细器件指引、经验证的场求解器、工厂工艺与工程师评审是彼此独立的证据类别。来源、项目契约、网络身份、规则文件或几何的变更会使受影响检查失效。始终把证明绑定到确切的设计修订，避免用实验性工具写入活动项目。
