# 有来源依据的备选项、DNP 与可测试性

只有出于有依据的电气、采购、装配或诊断目的才保留备选器件。0 欧姆跳接、DNP 封装、备选选择器、跳线或串联器件并非天然无害。记录必需/可选状态、理由、位号、确切的默认装配状态与取值/MPN、备选变体、互斥规则，以及实际的切换/保护影响。

## 三阶段评审

**原理图：**核验拓扑、正常装配与 DNP 两种状态、电气限值与来源；检查 0 欧姆替换是否会破坏反馈、限流、阻抗匹配、滤波或安全。**布局：**确认真实封装/焊盘存在、残桩残留、回流环路、敏感 RF/时钟/高速影响、载流能力、机械/Courtyard 可达性与可测试性。**生产：**核验选定装配 BOM/CPL、DNP/装配/MPN 一致性、互斥装配数量边界与真实工程处置。已删除的占位不应仍出现在原理图、PCB 或 BOM 中。

`reserve_review.py` 检查有界的结构契约；它不能取代基于来源的电气安全或 SI/EMC 评估。任何缺失的安全证据、无效备选、过期板卡 SHA、缺失变体证明或不匹配，都按风险等级构成阻断或在跟问题。不得静默替换备选器件，也不得把 0 欧姆电阻当作未经评审的电气元件使用。

参见 [工程规则](engineering-rules.md)、[设计意图](design-intent.md) 与 [制造](dfx-npi.md)。
