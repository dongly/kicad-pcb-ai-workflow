# 实验性的离线网格/A* 布线搜索

Python 布线搜索模块是**候选路径算法**，不是 KiCad PCB 写入后端。它在选定网格上对
指定焊盘/网络端点、障碍物、板边/禁布区与层间过渡建模，然后搜索有边界的路径。它要求
显式提供层映射、布线宽度/间距、过孔钻孔/直径、坐标、网格步距、允许的网络类与受保护
铜皮。不得从原理图静默推断真实的制造约束。

真实路径安全性要求 KiCad 原生几何与 DRC，超出网格近似所能覆盖的范围：圆弧与焊盘
形状、精确间距、叠层、过孔规则、电气回流、阻抗/长度/相位、制造公差与既有布线。
检测到的候选失败、预算上限或不支持规则，必须与一次成功*已应用并已验证*的 KiCad
布线区分开。

布线计划输出可由 AI 用来选择一个已验证的 Konnect 操作，但只有 Konnect 才写入活动板。
必须独立回读实际的网络/走线/过孔对象，保存/重载并运行 DRC 与 G4。不得把该实验性
搜索称为自动布线器，也不得把它的 JSON 当作原生铜皮。

要获得当前确切的参数，请运行 `python scripts/script_route_search.py --help` 并查看
[布线策略](constraint-routing.md)。
