# Konnect-EDA 历史本地夹具证据

本文件汇总**有界的历史记录**，不是对每个已发现 MCP 工具的普适验收。采样环境为
Windows x64、KiCad 10.0.8 与特定的本地安装 Konnect-EDA 版本。报告的工具数量随后端
构建与已加载工具集而变化；只有**当前实际发现的 schema** 才是相关的。

小型代表性测试包括连接、有限的器件移动/旋转、选定的原理图符号/字段/网络操作、
简化的原理图到 PCB 同步、单网络布线拒绝/接受用例与受控导出候选。复杂层次化原理图、
全自动多层布线、复杂的自定义焊盘/铜区几何、SI/PI 与工业级 DFX/NPI 需要单独的获
认可夹具与当前项目的原生检查。

R10 策略是动态发现 + L0–L3 风险分级 + 限定范围的验收。没有证据时，不得把验收记录
跨可执行文件 SHA、KiCad 版本、输入 schema、对象类型或操作范围迁移。参见
[Konnect 迁移](konnect-capability-migration.md)。
